# 🏢 Meeting_Room 

> เว็บแอปพลิเคชันสำหรับจองห้องประชุม  

## 🚀 Features
ระบบแสดงข้อมูลการจอง ค้นหา แก้ไข และยกเลิกการจองตามสิทธิ์ของผู้ใช้งาน
ตัวอย่างเว็บ

### 1. Clone โปรเจค
```bash
https://github.com/Cannabiscafe67/Project-Meeting-room.git
```
### 2. รัน Development Server
```bash
python manage.py runserver
```
